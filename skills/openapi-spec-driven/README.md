# OpenAPI Spec-Driven Development

- **Kategori:** Backend API dan Realtime
- **Level:** Intermediate
- **Topik:** contract-first, OpenAPI 3.1, codegen, schema validation

## Ringkasan

Panduan pengembangan API berbasis kontrak dengan OpenAPI 3.1: mendesain spec dulu, memvalidasi request/response, men-generate client/server, dan menjaga spec tetap sinkron.
