# GitHub Actions Workflow Engineering

> **Kategori:** DevOps dan Cloud | **Level:** Intermediate

Panduan menulis GitHub Actions workflows yang cepat, aman, dan mudah dirawat: caching, matrix, OIDC, dan reuse.

## Yang Dipelajari
- Struktur job dan step: kapan pecah job, kapan digabung
- Caching yang benar (dependencies, build artifacts, Docker layers)
- Matrix build tanpa duplikasi konfigurasi
- Keamanan workflow: least privilege permissions, OIDC, pinning actions
- Reusable workflows dan composite actions untuk menghindari copy-paste

## Production Outcome
CI yang selesai dalam hitungan menit, tidak menyimpan secret lebih dari yang perlu, dan tidak perlu diedit di lima tempat saat pola berubah.
