# Anti-Slop Test Quality

> **Kategori:** Testing / Code Quality | **Level:** Intermediate–Advanced

Panduan membedakan test yang benar-benar memverifikasi behavior dari test kosmetik, tautologis, flaky, atau terlalu bergantung pada implementation detail.

## Yang Dipelajari
- Strong assertions and meaningful failure cases
- Test mutation resistance
- Mock boundaries and fixture quality
- Flake prevention
- Test coverage that reflects risk
