# Web Localization & i18n

- **Kategori:** Frontend dan Web Design
- **Level:** Intermediate
- **Topik:** i18n, l10n, RTL, pluralization, locale routing, translation workflow

## Ringkasan

Panduan internasionalisasi aplikasi web: arsitektur i18n, file terjemahan, pluralization, dukungan RTL, locale routing/SEO, dan alur kerja terjemahan yang terawat.
