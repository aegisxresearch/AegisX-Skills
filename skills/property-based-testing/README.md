# Property-Based Testing

- **Kategori:** Programming dan Workflow
- **Level:** Intermediate–Advanced
- **Topik:** properties, generators, shrinking, invariants

## Ringkasan

Panduan property-based testing: menguji invariants dengan input acak yang di-generate, shrinking untuk reproduksi, dan strategi memilih properties yang bermakna.
