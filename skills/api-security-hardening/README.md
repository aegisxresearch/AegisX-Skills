# API Security Hardening

- **Kategori:** Security
- **Level:** Intermediate–Advanced
- **Topik:** OWASP API Top 10, authn/authz, input validation, rate limiting

## Ringkasan

Panduan mengamankan API berdasarkan OWASP API Security Top 10: otentikasi dan otorisasi yang benar (termasuk object-level), validasi input, rate limiting, dan respons insiden.
