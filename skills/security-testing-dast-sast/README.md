# Security Testing: DAST & SAST

> **Kategori:** Security | **Level:** Intermediate-Advanced

Panduan menggabungkan SAST (static analysis) dan DAST (dynamic analysis) untuk menemukan kerentanan sebelum dan sesudah deployment.

## Yang Dipelajari
- Perbedaan SAST vs DAST vs SCA dan kapan masing-masing menemukan bug
- Integrasi SAST di CI dengan baseline dan suppressions yang terkelola
- DAST dengan OWASP ZAP: spider, active scan, dan auth context
- Triase temuan: false positive vs actionable finding
- Metrik: time-to-detect, escape rate, dan fix SLA

## Production Outcome
Pipeline security testing yang menemukan kerentanan sebelum rilis dan mendeteksi regresi sebelum mencapai produksi.
