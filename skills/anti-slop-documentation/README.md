# Anti-Slop Documentation

> **Kategori:** Documentation / Code Quality | **Level:** Intermediate–Advanced

Panduan menghasilkan dokumentasi yang spesifik, dapat diverifikasi, jujur tentang batasan, dan benar-benar membantu pembaca mengambil keputusan.

## Yang Dipelajari
- Claim-to-evidence writing
- Runnable versus illustrative examples
- Trade-offs and failure modes
- Reference quality and freshness
- Documentation consistency and maintenance
