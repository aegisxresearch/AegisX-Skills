# Anti-Slop Code Review

> **Kategori:** Code Quality / AI Engineering | **Level:** Intermediate–Advanced

Panduan menemukan kode yang terlihat meyakinkan tetapi tidak diperlukan, tidak terpakai, sulit dirawat, atau tidak sesuai dengan behavior yang diminta.

## Yang Dipelajari
- Scope and intent verification
- Unnecessary abstraction and duplication detection
- Error handling and type-quality review
- Complexity, dead code, and maintainability checks
- Evidence-based review output
