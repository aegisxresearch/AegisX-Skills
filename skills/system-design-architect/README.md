## Deskripsi
Panduan system design: architecture patterns, scalability, microservices, dan distributed systems.

## Yang Dipelajari
- Architecture patterns (monolith vs microservices)
- Scalability patterns (horizontal scaling, caching, database replication)
- Message queue patterns (pub/sub, event sourcing, CQRS)
- Resilience patterns (circuit breaker, retry with backoff)
- Design checklist untuk production systems
