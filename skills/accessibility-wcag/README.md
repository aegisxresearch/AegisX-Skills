# Accessibility & WCAG Engineering

> **Kategori:** Frontend / Security | **Level:** Intermediate–Advanced

Panduan membangun antarmuka web yang dapat digunakan dengan keyboard, screen reader, dan teknologi bantu lain.

## Yang Dipelajari
- WCAG 2.2 principles and conformance
- Semantic HTML, focus management, and ARIA
- Forms, dialogs, tables, and dynamic content
- Automated and manual accessibility testing
- Reduced motion, contrast, and inclusive error states

## Production Outcome
A repeatable accessibility review process with measurable acceptance criteria.
