# OpenTelemetry Distributed Tracing

> **Kategori:** DevOps dan Cloud | **Level:** Intermediate-Advanced

Panduan instrumentasi tracing end-to-end dengan OpenTelemetry: SDK, propagasi context, sampling, dan export ke backend observability.

## Yang Dipelajari
- Konsep trace, span, dan context propagation (W3C Trace Context)
- Instrumentasi otomatis vs manual dan batasannya
- Sampling strategy: head-based vs tail-based
- Export ke Jaeger, Tempo, atau vendor SaaS
- Menghubungkan trace dengan log dan metrics (correlation)

## Production Outcome
Satu request dari browser sampai database bisa diikuti dalam satu trace, dengan latency per hop terlihat dan sampling yang menjaga biaya.
