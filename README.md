## 📖 Tentang

Repository ini berisi kumpulan skills (panduan teknis terstruktur) yang mencakup **Backend API, Machine Learning, Web Design, Database, DevOps, Security, dan Programming**.

Setiap skill berada di folder sendiri dengan struktur:

```
skills/<nama-skill>/
├── README.md          ← Ringkasan: kategori, level, deskripsi, references
└── <nama-skill>.md    ← Isi skill lengkap: code examples, checklists, best practices
```

## 🚀 Cara Menggunakan

### 1. Clone repository
```bash
git clone https://github.com/aegisxresearch/AegisX-Skills.git
cd AegisX-Skills
```

### 2. Baca skill yang dibutuhkan
Setiap folder punya `README.md` sebagai ringkasan — mulai dari sana, lalu dalami file skill utama untuk code examples dan checklists.

### 3. Gunakan sebagai referensi
- 📋 **Checklist** — verifikasi pekerjaan sebelum deploy
- 💻 **Code examples** — template siap pakai
- ✅ **Best practices** — do's & don'ts yang sudah teruji

## 🤝 Kontribusi

Kontribusi diterima! Cara menambah skill baru:

1. Buat folder baru: `skills/<nama-skill>/`
2. Tambahkan `README.md` (kategori, level, deskripsi, references)
3. Tambahkan file skill utama `<nama-skill>.md`
4. Update tabel daftar skills di README ini
5. Submit Pull Request
